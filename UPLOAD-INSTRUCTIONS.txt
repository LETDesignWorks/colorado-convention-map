2027 COLORADO CONVENTION BUS ROUTE PLANNER UPDATE

1. Open the GitHub repository:
   LETDesignWorks/colorado-convention-map

2. Download and extract this ZIP file.

3. In GitHub, choose Add file > Upload files.

4. Drag the CONTENTS of the extracted folder into the upload area so the paths remain:
   index.html
   bus-access/app.js
   team/index.html
   routes/index.html
   routes/styles.css
   routes/app.js
   routes/hotels.js

5. Commit with a message such as:
   Add hotel-to-field-service bus route planner

6. GitHub Pages will republish automatically. The route planner address will be:
   https://letdesignworks.github.io/colorado-convention-map/routes/

No Firestore rule change is required for the first version. Saved route records are stored as administrator-only documents in the existing reviews collection.

Planning limitation: route times use OSRM/OpenStreetMap without live traffic or bus-specific restrictions. Verify final times and routing in Google Maps and with the bus operator.
