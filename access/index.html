Main account controls

Add as many individual logins as your planning team needs—there is no fixed user limit in this site. Your main account keeps full control and is the only account that can add, change or disable another user’s permissions.

Checking shared permissions…
Enable daily hosting plans for other logins

Your main login can save daily hosting plans now. Other users need Congregation Assignments view or edit access and the latest database rules.

  1. Download the updated Firestore rules.
  2. Open Firebase — Firestore Database — Rules. Keep a copy of the current rules, replace them with the downloaded rules, then click Publish.
  3. Refresh Congregation Assignments. The hosting planner checks shared access automatically.
Enable delegate counts for other logins

Your main login can use delegate counts now. Other users need Activity Planning view or edit access and the updated database rules.

  1. Download the updated Firestore rules.
  2. Open Firebase — Firestore Database — Rules. Keep a copy of the current rules, replace them with the downloaded rules, then click Publish.
  3. Refresh Activity Planning. Grant Activity Planning view access to see counts, or edit access to add, change and remove counts.
Enable service-day editing for other logins

Your main account can already save congregation service days. To let users with Congregation Assignments edit access save days too:

  1. Download the updated Firestore rules.
  2. Open Firebase → Firestore Database → Rules. Keep a copy of your current rules, replace them with the downloaded rules, and click Publish.
  3. Refresh Congregation Assignments. Day editing becomes available automatically for permitted accounts.
Finish secure permission setup
